# cryptography_library
- Библиотека решений задач из курса криптографии в университете

# 🛠️ Реализовано:
- Алгоритм Евклида (Простой и расширенный) - **gcd()** и **gcd_extended()** 
- Протокол Диффи-Хеллмана - **diffiehellman.h**
- Шифр Шамира - **shamir.h**
- Шифр Эль-Гамаля - **elgamal.h**
- Шифр RSA - **rsa.h**

# ⭐ Что можно улучшить:
- Создать генератор случайных простых чисел с проверкой на тест Миллера-Рабина
- Реализовать тип данных BIGNUM как в openssl (**1024 bit и более**)
- Создать тесты для функций через **gcov/lcov** (например)
- Создать библиотеку строк с динамической памятью

# 😏 Где применить:
